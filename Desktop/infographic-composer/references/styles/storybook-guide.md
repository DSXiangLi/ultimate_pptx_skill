# 视觉语言包 · storybook-guide 导览绘本风

儿童科普绘本的温暖手绘质感。亲和、叙事、降低专业门槛。
场景适配：S4 投教（首选）、S1 解读大众版、S2 陪伴（adverse 需"有出路"基调）。

## 画布
4:3 横版（1600×1200）默认；竖版传播图 3:4。

## tokens 绑定
- 调色板：**bound-set 默认 + open-with-rules 扩展**。默认按 nature 取：positive→P01 / steady→P02 / adverse→P03 / complex→P04。
  新包准入规则：base 为高明度低饱和纸感或天空渐变；surface 明度 ≥85% 且半透明；line 为棕/深灰系**非纯黑**；accent 中等饱和（禁荧光）；须含 accent_alt 供角色用色。
- 字体：T02 rounded-friendly（默认）或 T01 handwritten-warm（标题手写、正文仍圆润）。

## 工艺约束（质感/氛围/光线——本包不可替换部分）
**主场景**：占 35-50%，3/4 视角或半俯视，可出血；细节梯度：远简化/中细致/近精细；primary 色系主导。
**手绘四件套（必须全部应用）**：轮廓线 1.5-2.5px 粗细有变化（line 色）；水彩晕染（天空渐变+地面底色+主场景光晕，10-20% 透明叠加，边界自然晕开）；水彩纸纤维纹理全画面 5-10%；色彩轻微溢出轮廓线。
**光影**：柔和环境光，渐变阴影透明度 30-50%，无硬边。
**角色**：出现 2-4 次（开场 12-15% 画高→中途→结尾 8-10%）；版内外观/服装/配色完全一致；不遮挡主场景核心。

## must_avoid
数字插画的光滑渐变与均匀打光；高饱和荧光色；纯黑轮廓；信息框直角硬边；角色近似已有 IP；adverse 画成恐怖绝望（挑战可以，压抑不行）；正文用衬线或手写体。

## 槽位呈现表（契约 v2）
| 槽位 | 呈现 | 规格与文字预算 |
|---|---|---|
| TITLE | 顶部条居中/偏左，可手绘波浪饰线 | 主题 16-20pt 标题族 primary 色；副题 9-11pt text_secondary |
| DATA | 融入高潮点的数据牌（primary 项放大）或路线起点信息板 | primary 值 18-24pt accent 色+白描边；secondary 10-12pt |
| BODY·hero/causal/sequence 节点 | 知识站点四形态：导览牌/悬浮框（细线指向场景元素）/嵌入标签/对话气泡（≤2 个） | 徽章 30-40px accent+白字；题 8-10pt 粗；正文 6-7pt，**15-30 字/节点** |
| BODY·parallel（N6 时） | 绘本质感卡片：圆角+手绘框+水彩底 | 同上预算；类别色取 extras.category_badges 或 accent 系扩展 |
| BODY·contrast（N5 时） | 两侧场景色温对立（同包内），中线天平/路牌意象 | 每侧 point 15-25 字 |
| VOICE | 角色对话气泡 | 8-9pt 亲切口吻，**20-40 字**，署名并入末行 |
| LIST | 底部横向小卡 3-6 张 | name 7-8pt 粗；tag 8-9pt Mono accent；note 6pt；间距 8-10px |
| ASIDE | "小知识"角落框，2px 手绘线框 | 7-8pt，**20-40 字** |
| CAUTION | 路线末端/页脚上方警示牌 ⚠️ | 与节点同规格；warning 色框；**禁止任何装饰覆盖** |
| META | 最底 2-3% 横条 | 6pt text_secondary，`\|` 分隔 |

## 角色台词规则
开场欢迎+预告 / 中途解说（专业但口语化）/ 结尾总结+行动提示。事实信息必须来自契约。

## quality checklist
主场景占比与梯度成立；场景基调匹配 nature；角色原创且版内一致；节点可按编号追踪；手绘四件套在场；文字在预算内且与契约逐字一致；CAUTION 完整可读；整体温暖亲和。
