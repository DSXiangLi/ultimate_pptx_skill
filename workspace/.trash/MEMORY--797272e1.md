## 搜索规则

### memory_search 使用规范

**触发条件：** 在回答关于以下主题的问题前，必须先执行 memory_search：
- 之前的工作、项目或任务
- 决策记录
- 日期、事件、会议
- 人员信息、偏好
- 待办事项

**使用方法：**
```
memory_search(query="搜索关键词", maxResults=5)
```

**搜索结果处理：**
1. 如果找到相关信息，使用 memory_get 获取具体片段
2. 在回复中引用来源：`Source: <path#line>`
3. 如果搜索返回 `disabled=true`，告知用户记忆检索不可用

### 记忆文件结构

**MEMORY.md**（本文件）
- 长期保存的重要信息
- 经过整理的精华内容
- 用户偏好、重要决策

**memory/YYYY-MM-DD.md**
- 每日原始记录
- 会话日志
- 临时待办事项

### 更新规则

**何时更新 MEMORY.md：**
- 做出重要决策时
- 学到新知识或技能时
- 用户表达偏好时
- 发现更好的工作方式时

**何时更新每日日志：**
- 每次会话结束后
- 记录完成的任务
- 临时笔记和想法
