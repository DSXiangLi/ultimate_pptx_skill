# 目标
根据用户输入的目标公司（股票代码/名称），生成一份**高度结构化、数据完整、格式统一、分析深入**的可比公司分析报告。

# 执行流程（主智能体→子智能体模式）

## 步骤1：调用子智能体获取可比公司列表

使用 sessions_spawn 创建子智能体，任务描述：

```
## 任务：获取目标公司的可比公司列表

### 目标公司
[股票代码/名称]

### 执行步骤
1. 核心业务识别：明确公司的核心收入来源业务，明确产业链定位，技术演进和未来业务主要增长点
2. 可比公司识别与对比：
   - 位于相同的生态，公司业务存在全面竞争关系
   - 当前主营业务之一存在直接竞争关系
   - 公司未来技术演进、业务拓展方向存在重叠
   - 无直接竞争关系，但商业模式类似，未来增长曲线和估值可供参考
   - 如公司某业务属于近期市场热点板块，重点查找该业务可比公司

3. 工具使用：
   - 使用 find_comparable_companies 工具获取基础可比公司列表
   - 使用 th_search 通用搜索查漏补缺
   - 禁止直接查找同一三级行业公司作为可比公司

4. 分类整理：对可比公司进行分类，形成以下格式：
   - 分类1名称：说明分类逻辑，列出该分类下可比公司列表
   - 分类2名称：说明分类逻辑，列出该分类下可比公司列表
   - 分类3名称：说明分类逻辑，列出该分类下可比公司列表

### 输出
保存为 ~/Downloads/可比公司报告/[公司名称]-可比公司列表.md
```

## 步骤2：调用子智能体获取财务数据

使用 sessions_spawn 创建子智能体，任务描述：

```
## 任务：获取可比公司财务及估值数据

### 目标公司
[股票代码/名称]

### 可比公司列表
[从步骤1获取的可比公司列表]

### 执行步骤
1. 使用 gildata_query 工具获取可比公司的财务数据：
   - 营业收入、归母净利润、经营现金流、EPS、ROE
   - 市值
2. 使用 gildata_query 工具获取估值数据：
   - PE、PB、PS、EV/EBITDA
3. 仅获取A股、港股上市公司的财务及估值数据
4. 财务工具无法获取的公司使用 th_search 补充

### 财务数据要求
- 历史数据：2024A年报数据
- 预测数据：2025E、2026E、2027E券商一致性预测
- 单位：亿元（除EPS为元）
- 缺失数据用"--"表示

### 输出
保存为 ~/Downloads/可比公司报告/[公司名称]-财务数据.md
```

## 步骤3：主智能体汇总生成报告

# 字段定义与填充标准

## 业务对比表
- **业务相似度**：★★★★★制，5星为最高相似度
- **相关业务最新进展**：50字内具体描述，包含关键客户、订单、技术突破等

## 财务数据标准
- **历史数据**：统一使用最近一年年报数据
- **预测数据**：使用券商一致性预测
- **单位统一**：亿元（除EPS为元）
- **格式要求**：数字右对齐，保留2位小数，使用"--"表示缺失或无效数据
- **禁止计算**：财务数据以财务工具返回及公告为准，禁止自行计算或估算

## 估值数据标准
- **PE处理**：亏损公司PE填写"--"
- **分位数**：基于过去12个月历史数据计算
- **预测估值**：基于预测净利润计算

# 数据验证与质量控制

**生成前检查清单：**
- [ ] 目标公司分析是否准确、深入
- [ ] 可比公司分类逻辑是否清晰
- [ ] 业务对比表字段是否完整
- [ ] 财务数据是否包含历史+预测
- [ ] 估值表是否包含PE/PB/PS/EV/EBITDA
- [ ] 所有数字是否已正确右对齐（使用`---:`）
- [ ] 缺失数据是否用"--"表示
- [ ] 预测数据是否标注"E"

# 约束条件
- 报告必须基于真实可靠的市场数据
- 不得虚构财务数据或事件
- 数据缺失必须明确标注
- 财务工具无法获取的公司可使用搜索补充，数据源仅使用web、report
- **子智能体独立完成各环节，主智能体负责汇总**
