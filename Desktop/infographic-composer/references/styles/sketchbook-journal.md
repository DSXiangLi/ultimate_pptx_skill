# 视觉语言包 · sketchbook-journal 手账笔记风

投资者的私人笔记本 + 创意采集簿。羊皮纸、胶带、墨点、手绘框——个性化日记感与手工温度。
场景适配：S2 陪伴（首选：持有人信/震荡市手记）、S4 投教要点卡、S1 轻量解读笔记。
**天然搭配 N6 卡片集**（parallel 拓扑），亦适配 N4 手账时间轴。

## 画布
4:5 竖版（1080×1350）默认——社交传播比例；横版不建议（手账气质依赖竖向翻页感）。

## tokens 绑定
- 调色板：**bound-set 默认 + open-with-rules 扩展**。默认：P05 parchment-cream（温暖文具）/ P06 playful-stationery（趣味涂鸦，投教轻松向）/ P07 vintage-sepia（复古怀旧，周年回顾向）。
  新包准入规则：base 必须是纸色（高明度低饱和，米/奶/泛黄系）；须提供 extras.category_badges ≥4 个可区分色相（卡片类别编码用）；line 用 primary 的 60% 透明变体或灰棕系。
- 字体：**T01 handwritten-warm**（标题手写/书法感，正文圆润无衬线——正文禁手写体）。

## 工艺约束（质感/氛围/光线）
**纸基**：羊皮纸/艺术纸纹理全页 10-15% 透明度；可选极轻网格纹 1-2%、四角做旧泛黄 3-5%、铅笔草稿痕 <1%。
**装饰预算（总装饰占页面 3-8%，逐项上限）**：
- 胶带碎片：宽 3-5px 长 20-50px，可带网格/虚线纹，accent 系或暖色，用于"固定"标题/色板/卡片一角
- 墨点水滴：3-8 处，直径 3-8mm，浅褐/蓝，透明度 30-50%，只在边角装饰区
- 植物涂鸦：页缘叶/花/藤蔓细线条，黑/灰极轻，<3% 面积
- 星星钻石：直径 4-6mm，accent 或 accent_alt 色，3-8 个，<5% 覆盖
- 手绘元素：不规则强调框、手写箭头/标注线、随性下划线圆圈，灰或 secondary 色
**水彩**：标题区与卡背景极轻晕染 5-10% 透明度，柔和蓝/粉紫。
**光线**：柔和台灯暖光感（warm）/ 多彩轻快（playful）/ 泛黄晨光（vintage），无方向性硬阴影。

## must_avoid
装饰覆盖任何正文（**尤其 CAUTION/META 区，半径 30px 内禁止任何墨点/胶带/涂鸦**）；装饰总量超 8%（杂乱失控）；数字感光滑渐变与硬投影；卡片机械完美对齐（允许 ±1-2° 微倾或手绘不齐框，但网格基线对齐、倾斜不超此值）；正文手写体；荧光标记大面积使用（仅 playful 包允许小段荧光下划线）。

## 槽位呈现表（契约 v2）
| 槽位 | 呈现 | 规格与预算 |
|---|---|---|
| TITLE | 顶部横幅 15%：手写大标题+左上胶带碎片+右上水彩点/墨点/小星 | 主题 40-48pt 手写族 primary 色可跨 2 行；副题 18-24pt 用「」括起 text_secondary |
| category_legend（N6） | 标题下"参考色板条"8-10%：色块 30-40px+下方标签，胶带模拟固定 | 标签 8-9pt；色块取 extras.category_badges |
| DATA | 色板下数据条 10-12%：手绘箭头/闪电/星标+大号数字，手绘分隔符（竖线/星号/小叶） | label 9pt；value 20-28pt Mono，方向色：↑暖红 ↓蓝 →金（从包内取） |
| BODY·parallel（N6） | 3 列卡片网格：圆角卡 surface 底+细 line 框 2-3px（可手绘不齐），左上彩色圆徽章（36-40px 类别色+白数字），徽章下类别小标 | 卡题 10-12pt 粗；正文 9-10pt 行距 1.3 共 3-5 行，**40-80 字/卡**；底注"Sample:/备注:"7-8pt 斜体；右下极轻小插画 20-40px |
| BODY·sequence（N4） | 手绘蜿蜒虚线轴+日期小旗，节点=便签卡（微倾±1-2°） | marker 手写 9pt；节点正文 30-60 字 |
| BODY·hero/causal（N1 手账冒险页） | 手绘地图式路线+便签站点 | 节点 20-40 字 |
| VOICE | 便签纸卡（一角胶带固定，微倾） | 引文 9-10pt，**30-80 字**；署名 8pt 手写族 |
| LIST | 横排小标签条（书签意象） | name 8pt；tag 8-9pt Mono accent；note 7pt |
| ASIDE | 解说面板：左竖色条（accent 底白字"说明"，8-10% 宽）+右侧 3-5 条要点 | 9-10pt 行距 1.4 |
| CAUTION+META | 艺术页脚 10-12%：左 60% 合规文字（分段排列），右 40% 手绘静物装饰（书堆/调色盘/笔杯/便签"Keep Learning"，线条画轻上色 30-60px） | 文字 8-9pt 灰**但对比度须达可读下限**；装饰与文字间留 ≥20px 安全距 |

## quality checklist
纸纹与装饰各项在预算内；装饰未触碰任何正文与 CAUTION/META 安全区；卡片徽章类别色与 legend 一致；微倾 ≤2°且基线对齐；正文非手写体；文字与契约逐字一致；整体气质：手工温度、日记感、乱中有序。
