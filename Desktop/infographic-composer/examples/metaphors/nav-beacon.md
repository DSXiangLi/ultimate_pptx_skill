# 风浪中的灯塔航线（adverse · S2 陪伴）
来源：基金陪伴内容，基金语义内生隐喻

```yaml
metaphor_card:
  name: 风浪中的灯塔航线
  trigger: adverse + S2陪伴（回撤/震荡市/持有人安抚）
  one_line: 船只在波涛中稳健前行，远方灯塔始终可见——挑战可见，出路更可见
  mapping:
    - concept: <当前市场波动/回撤>     element: 海浪（高度体现波幅，但船未倾覆）
    - concept: <基金/投资组合>          element: 船只（结构稳固，旗帜可辨认）
    - concept: <POINTS 持有理由/支撑>   element: 船身各处标牌（分散锚定点，不随浪飘）
    - concept: <HERO 结论/我们的判断>   element: 灯塔（远方，始终亮着，占画面 15% 高度）
    - concept: <时间/坚持>             element: 航线虚线（已走过的路 vs 剩余路程，比例可见）
  composition: 海面占画面 60%，船在中央偏左，灯塔在右上；天色阴但非黑暗（adverse 但有出路）
  route: 出发港（左下，已离开）→ 风浪区（中）→ 灯塔方向（右上，趋近中）
  anchors: POINTS 标牌沿船身分布（不遮船帆）；ASIDE 小知识在画面角落（如"历次回撤统计"）；CAUTION 在路线末端水面上的浮标
  must_avoid: 船不画成漂移/倾斜（稳健感必须）；灯塔不能太暗或被浪遮住（出路可见性第一）；
    浪不画成海啸（adverse 克制，不恐慌）；天色不用纯黑（dusk-grey 或阴云但有光线透出）
```
