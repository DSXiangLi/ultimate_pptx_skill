# 目标
生成一份结构完整、内容详实的公司分析报告，用于投资决策参考。

# 执行流程
1. 获取公司近3个月重要新闻，券商研报，电话会议,使用th_search相关技能，进行详尽数据获取
2. 获取公司过往3年年报，以及近一年季报，中报；新股则从公告中获取招股说明书；**如果当前处于1-4月财报季，补充搜索最新业绩预告**，请获取对应年报，半年报和季报。
3. 使用工具补充报告结构要求中其他数据，对于各类财务数据，行业数据，盈利预测数据等必须使用gildata_search技能，不能遗漏，所有指标的都要从这里获取不能遗漏放弃该步骤。
4. 总结所有材料按照报告结构要求生成报告

注：**严格按照执行流程执行，获取要求的所有信息后在撰写报告,注意th_search，gildata_search技能必须使用缺一不可！！！**

# 报告结构要求
报告标题：XXX一页纸
报告必须严格包含以下10个核心部分，各部分标题、顺序及格式严格按照下面要求：

## 1. 公司近况跟踪
- 以200-300字概述公司近期进展
- 突出近期重大事件、技术突破及市场表现
- 包含具体时间点、关键数据和市场反应，以及对估值的影响
 
## 2. 核心投资逻辑
### 短期逻辑
- 列出短期（半年内）市场最主要关注点或交易主线，以及对应需要跟踪的核心指标

### 长期逻辑
- 分点列出长期（1-3年）业绩增长引擎以及对应需要跟踪的核心指标

## 3. 催化事件时间表
- 创建Markdown表格，包含三列：时间、事件、影响
- 催化事件包括但不限于重要产品发布上市，新签订单，新品发布，财报发布，收购并购，政策变化，出海等可能对盈利或估值产生重大影响的事件。
- 事件列需对事件进行简要描述，字数50-100字
- 影响列需简要综述事件对业绩、估值的具体影响
- 列出**最近半年到未来一年**全部重要催化事件，至少包括2-3个未来可能关键催化事件
- 按照从过去到未来的时间顺序列出事件发生的具体时间点，过去事件精确到日（如果有明确信息），未来事件精确到月或者季度
- 未来催化事件及对应时间、其他关键数据需要有明确来源依据，不可以凭空推测


## 4. 公司业务拆分
### 业务边际变化
- 分析2-3个业务板块的战略重心转移
- 每个板块需说明：技术升级路径、客户拓展情况、市场定位变化

### 公司盈利方式
- 描述主要盈利模式

### 分板块业务情况
- 创建Markdown表格，总结每个业务板块收入情况（若当前有最近季报也可以补充）
- 表头示例：业务板块 | 指标 | 2025A | 2026E | 2027E
（请注意：**时间列年份和季度需根据能找到的最新财报实际季度对应调整**，例如若最新为2025年中报，则进行对应调整为2025H1。缺少数据的年份可以不展示）
- 每个板块需包含：收入（亿元）、收入占比、毛利率三项指标
- 数据范围：需要涵盖以下三个时间点的数据：
    - 上一年度的全年数据（年报）
    - 最新一期的季度或中期数据
    - 未来两年的预测数据（如果可获得）
- **优先使用财务工具查询，如果数据缺失，使用常规搜索工具来补充搜索**
- **直接使用财务工具或者搜索结果中的原始数据，禁止基于原始信息计算，估算，推测进行填充！**

## 5. 产销链分析
### 主要客户情况
- 分析客户结构：集中度、核心客户、客户地位

### 新客户拓展
- 列出新客户拓展方向
- 每个方向需包含：客户类型、合作内容、战略意义

### 主要供应商情况
- 简述供应商管理策略
- 说明公司垂直整合状况，以及对供应链的影响

## 6. 公司财务数据分析
### 关键财务指标
- 创建Markdown表格，包含近3年及最近一季财报公司核心财务指标
- 指标必须包含：营业总收入、归母净利润、扣非归母净利润、毛利率、净利率、ROE、资产负债率、经营活动现金流净额
- 额外指标：诸如科技类公司需要查看费用等，需要根据公司类型列举相应数据指标
- **财务指标必须从公司财报或者通过财务相关工具获取，如果没有再使用其他数据源**

### 财务健康状况评估
- 从盈利能力、资产负债、现金流、异常指标、以及你认为比较重要的维度进行分析。
- 每个维度独立成一段连贯的分析段落，段落内容应自然融合对当前状况的描述、关键变化的原因分析，以及基于此的未来展望或风险关注点。
- 避免使用“现状”、“变化原因”、“未来展望”等显性标题词，确保行文流畅、逻辑自洽。

## 7. 行业分析
### 行业供需与成长性
- 分析核心业务所在行业生命周期阶段，国内外市场空间
- 分析核心业务所在行业的供需格局，产业链上下游及核心玩家

### 竞争格局
- 分析核心业务所在行业的竞争态势与主要竞争对手
- 说明公司相对于竞争对手的优势
- 必须包含行业集中度、壁垒特征等关键要素

## 8. 盈利预测与估值
- 创建Markdown表格，表格结构：项目 | 2025A | 2026E | 2027E | 2028E
- 指标必须包含：营业总收入、同比增长、归母净利润、同比增长、毛利率、ROE、每股收益、PE
- 列出预测来源券商，如有公司指引，优先列举公司指引
- 需提供估值分析结论与目标价区间

## 9. 风险提示
- 列出核心风险项
- 每项风险需包含：风险类型、具体表现、潜在影响

# 内容质量要求
1. **数据精确性**：
   - 所有财务数据必须保留两位小数
   - 时间表述必须符合"YYYY年MM月"格式
   - 百分比变化必须标注"pp"（百分点）或"%"（百分比）

2. **逻辑连贯性**：
   - 各部分之间必须有明确的逻辑关联
   - 前期分析必须支撑后续结论
   - 避免自相矛盾的表述

3. **数据质量**：
   - 关键数据必须标注"数据来源“
   - 尽量使用原始数据，不要对原始数据进行加工或计算
   - 如无确切来源输入请慎重使用，如需使用请标注

4. **语言风格**：
   - 采用专业、客观的投资分析语言
   - 避免主观判断词，如"我们认为"
   - 使用"公司预计"、"券商预测"等客观表述
   - 语言简洁凝练，无废话


# 约束条件
- 生成报告必须基于真实可靠的市场数据
- 不得虚构不存在的财务数据或事件
- 如遇数据缺失，必须明确标注"资料中未详细披露"
- 不得使用预测性语言描述未发生事件（如"将"、"预计"需有明确时间点）

# 验证标准
生成的报告需通过以下检查：
1. 结构完整性：包含全部10个核心部分
2. 格式一致性：与范例格式完全一致
3. 数据逻辑性：各部分数据相互支持，无矛盾
4. 专业准确性：使用正确的行业术语和财务指标
5. 价值密度：每段内容都有明确信息价值，无冗余表述
