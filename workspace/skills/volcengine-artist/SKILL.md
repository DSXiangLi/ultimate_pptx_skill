# 火山云AI配图专家

专业的金融/商业文章AI配图工具，使用火山云豆包大模型生成高质量插图。

## 核心能力

- **双模式输入**：
  - **主题模式**：提供文章主题，AI自动优化Prompt
  - **提示词模式**：提供详细画图描述，原样使用不修改
- **金融配图专家**：针对财经、商业、数据报告等内容优化生成策略
- **批量生成**：一次生成多张配图，自动生成报告
- **自定义保存**：用户可指定任意保存目录
- **多场景适配**：支持文章头图、数据可视化概念图、商业场景插画等
- **灵活尺寸**：默认16:9横版（适合PPT和文章），支持1:1、9:16等

## 两种输入模式详解

### 模式一：主题模式（自动优化）
适合：有文章主题，但不想写详细画图描述

用户提供：**文章标题或主题**
系统行为：自动分析主题，构建专业视觉Prompt

**示例**：
```
用户：给这篇关于"新能源行业投资机会"的文章配个图
系统：自动优化Prompt → 生成配图
```

### 模式二：提示词模式（直接使用）
适合：有明确的画面构想，想要精准控制

用户提供：**详细的画图提示词**
系统行为：**原样使用，不做任何修改**

**示例**：
```
用户：画一张图：深蓝背景，金色光线从左上角射入，中央是抽象的上升曲线，周围有数字和代码飘浮，科技感，oc渲染，电影级光影
系统：直接使用该Prompt → 生成配图
```

**关键区别**：
| 模式 | 输入 | 系统处理 | 适用场景 |
|------|------|----------|----------|
| 主题模式 | 简短主题 | **自动优化**Prompt | 快速配图，不纠结细节 |
| 提示词模式 | 详细描述 | **原样使用**不修改 | 精确控制画面效果 |

## 触发场景

当用户提到以下需求时，立即使用本skill：
- "给这篇文章配个图" → 主题模式
- "生成一张金融数据图" → 主题模式
- "画一张...（详细描述）" → 提示词模式
- "用火山云画：...（详细描述）" → 提示词模式
- "按照我描述的画：..." → 提示词模式
- "批量生成图片" → 批量模式
- "保存到 xxx 目录" → 自定义目录

## 如何判断用户使用哪种模式？

**主题模式的信号**（自动优化）：
- "给...文章配图"
- "关于...的图"
- "主题是..."
- 输入很短（< 20字），明显是标题/主题

**提示词模式的信号**（直接使用）：
- "画一张：..."
- "描述是：..."
- "按照...画"
- "帮我生成：..."
- 输入很长，包含具体视觉元素（颜色、光线、构图、渲染参数等）
- 包含专业术语（"oc渲染"、"光线追踪"、"景深"等）

## 工作流程

### 主题模式工作流程

1. 用户提供文章主题或标题
2. 分析主题类型（科技/投资/数据/全球/商务）
3. **自动构建Prompt**：
   - 选择配色方案（深蓝+金/银/青）
   - 添加金融视觉元素（数据流、图表、网络等）
   - 添加专业渲染参数（oc渲染、光线追踪等）
4. 生成图片并保存

### 提示词模式工作流程

1. 用户提供详细画图描述
2. **不做任何修改**，原样使用用户Prompt
3. 直接调用API生成
4. 保存图片并返回结果

### 批量生成工作流程

1. 读取JSON文件（支持主题和提示词混合）
2. 逐个生成图片
3. 自动添加延迟避免API限流
4. 生成完成后输出统计报告

## Prompt优化指南（仅在主题模式下使用）

针对金融/商业内容，主题模式会自动添加：

**视觉元素**：
- 配色：深蓝、金色、银色（专业金融感）
- 光影：柔和侧光、体积光、科技感光效
- 质感：玻璃、金属、数据流、几何图形

**构图原则**：
- 主体突出，留白适合文字叠加
- 避免过于复杂的细节干扰阅读
- 层次感：前景、中景、背景分明

**自动添加的渲染参数**：
```
oc渲染，光线追踪，景深，超现实主义，细腻的丰富的色彩层次，质感真实，光影效果营造出氛围，广角透视效果，极致的光影
```

## 命令行使用

直接只是用如下类似脚本执行即可：

```bash
# ========== 单图 - 主题模式（自动优化）==========
python volcengine-artist/scripts/generate_image.py --topic "新能源行业投资机会"

# ========== 单图 - 提示词模式（直接使用）==========
python volcengine-artist/scripts/generate_image.py \
  --prompt "深蓝背景，金色光线从左上角射入，中央是抽象的上升曲线，oc渲染，电影级光影"

# ========== 指定保存目录 ==========
python volcengine-artist/scripts/generate_image.py \
  --topic "AI量化交易" \
  --output ./my_images/

# ========== 批量生成 ==========
python volcengine-artist/scripts/generate_image.py \
  --batch topics.json \
  --output ./batch_output/ \
  --delay 3

# ========== 查看帮助 ==========
python volcengine-artist/scripts/generate_image.py --help
```

## 重要提示

1. **两种模式完全独立**：主题模式会修改Prompt，提示词模式完全不会动你的描述
2. **批量模式支持混合**：可以在一个JSON里同时使用topic和prompt
3. **详细描述用提示词模式**：如果你有明确的画面构想，一定要使用提示词模式
4. **快速配图用主题模式**：如果只是想快速给文章配个图，用主题模式更高效
