# Learning Log

This directory records problems discovered and solved while developing `ultimate-pptx-builder`.

## Rule

Before touching code related to a known problem area, read the corresponding learning note first. New problems and fixes must be added here with:

- context
- symptom
- root cause
- fix
- verification command
- files affected
- future prevention rule
