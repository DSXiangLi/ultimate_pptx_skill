# 学者猫头鹰（知识/教育向内容）
来源：科普内容示范卡

```yaml
character_card:
  archetype: 拟人动物
  species_or_form: 猫头鹰——知识科普类内容，取其"智慧+夜读"意象
  silhouette: 头身比 1:1.2，梨形圆身，短翼可比划手势；缩至 5% 画幅由"大圆头+羽角+圆框眼镜"辨认
  face: 双眼占脸部 45%，外加圆框细线眼镜（线宽与 style 轮廓线一致）
  outfit_props: 圆框眼镜；颈间小领结（accent 色）；翼下夹一册小书（书脊可印当次主题缩写）
  palette: guide_character 色羽毛 + 米白面部 + accent 领结
  expressions: 开场-展翼欢迎 / 解说-翼尖指牌+眼镜反光一闪 / 思考-翼托下颌 / 结尾-点头眯眼微笑
  consistency: 眼镜/领结/书册/羽色全版不变
  must_avoid: 不近似杜兰德/哈利波特海德薇等可指认形象；爪部简化为圆角色块，不画利爪
```
