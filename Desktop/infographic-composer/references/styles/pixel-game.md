# 视觉语言包 · pixel-game 像素艺术游戏风

星露谷物语/Habbo Hotel/FC 游戏的 UI 美学：所有内容装入虚构界面系统，UI 元件承担叙事结构。
**视觉冲击来源：界面元数据（血量条/对话框/物品栏）× 像素工艺纪律。**
场景适配：S4 投教（轻松关卡式，首选）、S2 陪伴（治愈游戏感）、S1 解读（年轻受众版）。

## 画布
9:16 竖版（1080×1920）默认；可选 4:3（复古显示器比例，retro 氛围用）。

## tokens 绑定
- 调色板：**bound-set → {P16 pixel-retro, P17 pixel-cyber, P18 pixel-pastel}**。
  按氛围选：温馨复古→P16 / 赛博朋克→P17 / 治愈马卡龙→P18。
  三包共享像素纪律：总色数 ≤ 32 色；extras.crt_scanline 必须应用；禁止超出包定义的色相。
- 字体：**locked → T06 pixel-8bit**。像素对齐是风格本体，不可替换。

## 全像素-全对齐原则（最高约束）
所有视觉元素对齐到基础像素单位（16px 或 32px 网格）；禁用抗锯齿；渐变用 dithering（Bayer 或 Floyd-Steinberg 抖动图案，非平滑渐变）；所有边框为 2-4px 硬边像素描边。

## 工艺约束（不可替换部分）

**UI 框架纪律**：
- 游戏窗口标题栏：必有（3-4px 像素描边 + 右上角最小化/关闭像素按钮 + 小标题）
- 对话框：必有三角指向（NPC 一侧），带姓名框（像素矩形）
- 所有面板背景：surface 色半透明（模拟像素半透明）+ 双层像素描边（外 3-4px + 内 1px 高光色）
- 像素阴影：关键 UI 元件右下各偏移 4-8px 的深色像素块（伪 3D 投影）

**动画暗示（静态表现）**：
- 数字跳动：同一数字显示 2-3 帧残影（向上偏移 2-4px，opacity 递减 60%/30%）
- 闪烁元素：用双色交替像素格（如黄/橙交替 2×2 格）暗示闪烁
- 滚动文字：运动模糊（水平拖影，最右像素延伸 4-8px，opacity 递减）
- RPG 属性条：████░░ 格式，每格 8×8px，满格 accent 色，空格 surface 色

**CRT 效果（全画面叠加，每个 preset 必须）**：
- 横向扫描线：深色横线 1px，间距 2px，opacity 8-12%，覆盖全画面
- 可选：画面四角轻微暗角（vignette，opacity 15-20%）

**像素装饰件**：
- 分隔线三选一：8bit 波浪线（3px 高锯齿波）/ 重复像素图案（★/♦/·循环）/ 像素虚线+节点
- 光标图标（像素箭头/手型，16×16px）置于关键信息入口
- 边角装饰：L 形或十字像素装饰（8×8px）置于面板四角
- 物品栏格子：深色背景 + 高光（左上 1px 亮色）+ 阴影（右下 1px 深色），伪 3D

## must_avoid
抗锯齿/平滑曲线（硬边缘是灵魂）；超过 32 色；平滑渐变（必须改成 dithering）；
非像素对齐的字号（如 13pt——必须用 16pt 或 8pt）；真实摄影图像混入；
UI 框架装饰 > 30% 画面（内容先于装饰）；中文使用普通字体（必须像素/点阵感）。

## 视觉冲击构建流程（替代"选场景隐喻"步骤）
Step 1：读 protocols §6，填写 ui_metaphor_card（界面系统名+契约→UI元件映射）。
Step 2：render spec B 层写"界面构成说明"——哪些 UI 元件承载哪些契约槽位，UI chrome 装饰件清单。

## 槽位呈现表（契约 v2）
| 槽位 | 呈现 | 规格与预算 |
|---|---|---|
| TITLE | 游戏窗口标题栏：3-4px 描边+像素 logo（32×32）+ 中央品牌像素字+右侧像素按钮组 | 字：T06 中号像素；下方像素分隔线；CRT 扫描线叠加 |
| DATA | RPG 属性条展示：label 小像素字 + ████░░格式进度条 + 数值 | 条格 8×8px；满格 accent；数值 T06 大号；双帧残影暗示跳动 |
| BODY·parallel（N6）→物品栏 | 3×N 像素格子网格：48×48px 图标位+name+code（稀有度彩边：金/紫/蓝/白） | code T06 加粗 accent；name T06 小号；icon 像素绘制 48×48 |
| BODY·sequence（N4）→任务日志 | 📜 QUEST LOG 对话框：每 stage 一条任务条目，climax 条目高亮（accent 背景） | 条目：像素图标前缀+text；30-50字/条；完成状态可用 ✓ 像素符号 |
| BODY·hero/causal（N1）→主面板对话框 | 主游戏窗口：左侧 64×64 像素头像（代表主体）+ 右侧 headline+属性条 | headline T06 大号；节点 **20-40 字**（像素字节约） |
| BODY·causal layers（isometric 可选） | 可用像素等轴测风格的分层剖面（each layer 为独立像素方块层）| 层标签 T06 小号；连线 2px 像素线 |
| BODY·contrast（N5）→双窗口 | 左右各一游戏窗口，side_a/side_b | 每侧 point 15-25 字 |
| VOICE | NPC 对话框：32×32 像素头像（点阵绘制）+ 对话框 + 三角指向头像 + 姓名框 | 引文 T06 中号，**30-60 字**（像素字节约）；attribution=姓名框 |
| LIST | 物品栏/背包：3 列网格，每格含产品像素图标+name+code+稀有度边框 | code T06 accent；稀有度：金>紫>蓝>白 |
| ASIDE | 💡 道具说明框：左侧小像素图标+右侧说明 | T06 小号，**15-30 字** |
| CAUTION | ⚠️ 系统警告框：红色 3px 边框，闪烁暗示（双色交替格）+ 滚动公告栏 | T06 最小号；**禁止 UI 装饰覆盖文字区** |
| META | 底部系统消息框：半透明黑底 + 小号像素字 + >>> 前缀 | 最小像素字（8pt 点阵）；text_secondary 色 |

## quality checklist
像素对齐全画面无例外；色数 ≤ 32 色；CRT 扫描线在场；UI 窗口框架完整（标题栏+描边+像素阴影）；
dithering 替代平滑渐变；物品栏/对话框等 UI 元件与契约槽位一一对应（ui_metaphor_card 已填）；
文字可读（点阵字体+1-2px深描边）；CAUTION 警告框样式正确且内容可读；
整体气质：打开这张图像进入了一个游戏界面，信息在游戏中自然流动。
