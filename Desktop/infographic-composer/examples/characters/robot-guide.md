# 圆圆机器人导览员（科技/数据向内容）
来源：金融异动解读项目沉淀，已泛化

```yaml
character_card:
  archetype: 智能小机器人
  species_or_form: 球形小机器人——内容偏数据/理性时选用，传达"专业但不冷漠"
  silhouette: 头身比 1:1（头即半个身体），整体近似不倒翁轮廓；缩至 5% 画幅仍可由"圆头+短圆肢+头顶小天线"辨认
  face: 屏幕脸，双圆眼占脸部 40%，可切换表情图标；无嘴，情绪全靠眼与肢体
  outfit_props: 头顶单根天线（球端）；胸前圆形徽章（可印当次主题图标）；右手伸缩指示棒
  palette: style 的 guide_character 色为主体 + 白色面板 + accent 色徽章
  expressions: 开场-双眼弯月+挥手 / 解说-单眼放大镜图标+棒指信息牌 / 记录-双眼变笔记图标 / 结尾-双眼星星+竖拇指
  consistency: 天线/徽章/配色/肢体比例全版不变
  must_avoid: 不近似大白/瓦力/EVE 等已有 IP；不加写实金属反光；关节不画机械细节（保持圆润色块）
```
