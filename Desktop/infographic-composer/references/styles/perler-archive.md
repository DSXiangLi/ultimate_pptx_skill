# 视觉语言包 · perler-archive 拼豆档案风

100% 拼豆构成的像素化数据档案。理性、克制、现代工艺感。
场景适配：S1 解读专业版、S3 宣传数据型；受众为年轻专业人群。
**自带强布局语法（网格即风格），天然搭配 N3。**

## 画布
16:9 横版（1920×1080）默认，整面拼豆填满，无普通平面区域。

## tokens 绑定
- 调色板：**bound-set → {P08 cool-data, P09 warm-heritage, P10 mono-contrast, P11 tech-vivid}**。
  绑定理由：颜色角色=拼豆层语义，不对外开放。角色映射：base=底场豆 / primary=主图场豆（secondary=明度次级豆）/ accent=info 豆 / warning=accent 豆。色值：
  P08：#F0F0F0 / #1A3A52(#2C5F7B) / #0066FF / #FF3333
  P09：#FFF8E7 / #8B4513(#A0522D) / #D32F2F / #D4AF37
  P10：#FFFFFF / #000000(#4A4A4A) / #FF0000（唯一 accent）/ —
  P11：#FAFAFA / #2C3E50(#34495E) / #00D9FF / #FF6B6B、#4ECDC4
  文字叠加色 #000000 或 #2C2C2C（P09 用后者）。
- 字体：**locked → T04 condensed-data**。

## 全拼豆原则（最高约束）
一切视觉元素由拼豆构成；唯一例外：文字是叠加在浅色拼豆背景上的矢量字体。

## 工艺约束
拼豆：完美圆形 6-8px 直径、中心 1-2px 深色凹点、间距均匀 2px、哑光无高光、同色 ±3% HSV 微差、边缘锐利无抗锯齿。网格：8/10px 基准严格正交，禁止旋转。
主图场：60-70%，structure 豆构成，内部同色系 3-5 明度层级，外缘台阶化（1-2 豆宽）出血裁切。
负空间：浅豆 30-40%，拼图式咬合切入，禁止简单二分。
装饰件全拼豆：编号徽章 5×5/7×7、箭头 7×7/9×9、分隔线 1-2 豆宽、L 角标 3×3/5×5、bullet 单豆或 3×3。

## 文字叠加规则
文字区拼豆背景须浅色单一色调；字号 ≥6pt 行距 1.4-1.6；信息取向**节点少而厚**（反对压缩成短标签）。

## must_avoid
非拼豆平面色块/渐变混入；拼豆发虚/大小不一/间距漂移；旋转网格/有机曲线排列；主图场内部多色混拼；文字压深色豆或 <6pt；信息压缩成 2-6 字标签。

## 槽位呈现表（契约 v2）
| 槽位 | 呈现 | 规格与预算 |
|---|---|---|
| TITLE | 左上浅豆区 15-20%×8-10%，可 2 豆宽深框 | 主题 12-14pt Bold；副题 8-9pt |
| DATA | 右上数据簇浅豆区 12-15% 宽，四角 L 型 info 豆角标 | label 6-7pt；value 14-18pt Mono Bold info/warning 色 |
| BODY·hero（N3） | 主图场=HERO 形态（number→巨数字/趋势→巨箭头/object→轮廓/分析→图表碎片）；points 为右侧垂直堆叠浅豆分析区（20-25%×15-18%，5×5 豆编号徽章+1 豆深框） | 题 9-10pt Bold；正文 7-8pt 行距 1.5，**60-100 字/区**；keywords 粗+info 色 |
| BODY·sequence（N4） | 拼豆轴线（2 豆宽）横贯，节点为浅豆铭牌区，climax 区放大 1.5 倍 | 同上预算 |
| BODY·parallel/contrast（N6/N5） | 浅豆卡片网格/左右分场（两半各用一明度层级区分） | 卡正文 40-80 字 |
| VOICE | 下中浅豆区 25-30% 宽，左 3-4 豆宽 info 竖条 | kicker 7pt；引文 8-9pt 行距 1.6，**80-120 字**；emphasis warning 色；署名 6-7pt |
| LIST | 底横条浅豆区，1 豆竖线分隔 | header 8pt Bold；name 7pt；tag 8-9pt Mono info 色；status 5×5 豆箭头；note 6pt |
| 图例（本风格特有，建议保留） | 左下浅豆区，渲染真实 3×3 豆样本+标签 | 题 7pt Bold 标签 6pt |
| CAUTION | 页脚上方独立行，前置 3×3 warning 豆块 | 6-7pt；**周边禁止装饰豆侵入** |
| META | 最底 2-3% 浅豆条 | 6pt #505050 |

## quality checklist
100% 拼豆自查；豆规格统一网格正交；主图场占比/台阶/出血成立；负空间咬合非二分；BODY 节点 60-100 字、VOICE 80-120 字信息完整；图例渲染真实样本；文字与契约逐字一致；CAUTION 合规可读。
