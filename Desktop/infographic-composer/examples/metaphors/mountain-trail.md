# 登山路线（positive / steady 皆可）
来源：金融异动解读项目沉淀，已泛化

```yaml
metaphor_card:
  name: 登山路线
  trigger: positive（接近登顶构图）或 steady（半山推进构图）；要点为递进关系时最佳
  one_line: S 型山路自山脚营地蜿蜒至顶峰旗帜，沿途补给站即信息站点
  mapping:
    - concept: <起点/低谷/背景>              element: 山脚营地（帐篷+篝火）
    - concept: <POINTS[01..03] 各驱动/步骤>  element: 第 1/2/3 补给站（小木屋，外观各异）
    - concept: <HERO 目标/成果>              element: 顶峰旗帜 + 数值牌
  composition: 山体占画面 50%，3/4 视角，山脚出血至底边；路线为 accent 色点线，宽 4px
  route: 营地(左下) → 补给站×N(沿 S 路) → 顶峰(右上)
  anchors: 各站点导览牌立于木屋旁；HERO 牌系于旗杆；CAUTION 警示牌设在顶峰前最后一段陡坡旁（语义自然：登顶前提示风险）
  must_avoid: 山势不画成尖锐危崖（除非 adverse）；雪线/云层不遮挡任何站点牌
```
