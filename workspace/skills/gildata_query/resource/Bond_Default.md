## 字段说明

### InnerCode (债券代码)

债券代码（InnerCode）：与“债券代码对照表（Bond_Code）”中的“统一内部编码(不同市场交易的同一债券)（MainCode）”关联，得到债券的交易代码、债券简称等。

### DefaultProg (违约进度)

违约进度(DefaultProg)与(CT_SystemConst)表中的DM字段关联，令LB = 1900，得到违约进度的具体描述：101-预计利息违约，102-预计本金违约，103-预计本金和利息违约，201-利息违约，202-本金违约，203-本金和利息违约，301-撤销部分利息，302-撤销全部利息，303-撤销部分本金，304-撤销全部本金，305-撤销部分本金和部分利息，306-撤销部分本金和全部利息，307-撤销全部本金和部分利息，308-撤销全部本金和全部利息，309-和解撤销部分本金，310-和解撤销全部本金，801-其他违约，901-未违约。

### DefaultType (违约类型)

违约类型(DefaultType)与(CT_SystemConst)表中的DM字段关联，令LB = 2321，得到违约类型的具体描述：1001-公告预计违约，1002-信用评级，1003-触发投资者保护条款，2001-实质违约，2002-技术性违约，2003-本息展期，100301-触发交叉违约条款。
